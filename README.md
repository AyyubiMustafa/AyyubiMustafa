## 04 / HOW I THINK

I value three things in my development journey:

**01 — Understand Before You Memorize**  
Knowing why something works is more valuable than blindly copying code.

**02 — Build Before You Feel Ready**  
Small, completed projects create experience that tutorials alone cannot provide.

**03 — Improve Through Feedback**  
Errors are information. Code reviews are opportunities. Progress comes from being willing to learn.
